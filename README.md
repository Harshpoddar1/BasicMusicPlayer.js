# 🎵 Basic Music Player

A simple music player for the browser. Play songs, pause them, and move between tracks using clean on-screen controls.

Built with **HTML, CSS and JavaScript**, using the HTML5 `<audio>` element.

## ✨ Features

- Play / Pause
- Next and Previous track
- Song title display
- Simple, clean UI

## 🛠️ Tech Stack

| Part | Used for |
|------|----------|
| HTML | Player layout and the `<audio>` element |
| CSS | Styling the player and buttons |
| JavaScript | Controlling playback, switching tracks, updating the UI |

## 📁 Project Structure

```
music-player/
├── index.html
├── style.css
├── script.js
├── songs/        # your .mp3 files
└── README.md
```

## 🚀 Run Locally

```bash
git clone https://github.com/Harshpoddar1/<repo-name>.git
cd <repo-name>
```

Open `index.html` in your browser. To add your own songs, put `.mp3` files in the `songs/` folder and add them to the songs list in `script.js`.
